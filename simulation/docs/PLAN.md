# 历史计划说明

本文件原为 Spike-Topping Type III 可视化项目的早期概念草案，其中包含单
Harris 电流片、有限差分示例、人工喷流和预期输出等内容。当前实现已经采用
周期双 Harris 初值、FFT 伪谱导数、`2/3` 去混叠、RK4 时间推进，以及与
Type III 主脊相连的严格高频侧 spike 代理，因此旧草案不再作为方法或代码的
依据。

当前问题定义、公式、数值方法、代码映射、动画导出选项、科学边界和完整过程
记录统一维护在 [`../README.md`](../README.md)。

本轮没有运行模拟、测试或输出校验，也没有刷新历史结果和 PPT。
