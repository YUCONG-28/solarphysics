# Jet Lab 原型

Jet Lab 是独立启动的 PyQt6 喷流标注前端，不调用 PFSS 或射电高度反演。
交互流程参考 [SJET](https://github.com/songsolarphysics/SJET)，算法独立实现，未复制其代码。

## 启动

使用项目现有的 `solarphysics_env_latest` 环境和公共启动器：

```sh
Apps/run.sh frontend jet-lab --allowed-roots /absolute/observation/root --manifest /absolute/observation/root/paired_samples.json
```

也可用 `--left image.fits --right image.fits` 打开独立观测。多个允许目录用操作系统路径分隔符连接。
路径、样本和结果存放在私有配置或数据目录。查看器不下载数据，不启动远端连接。

## 一次标注

1. 两侧分别选择矩形或多边形 ROI；多边形双击完成。
2. 选择 percentile（默认 85）、manual 或 otsu。positive 提取正增强，negative 提取暗化。
3. 切换“点击目标区域”，点击要保留的连通结构。
4. 切换“点击内端”，在选中结构内点击内端附近。支段菜单列出通往各外端的候选；最长候选仍为待确认。
5. 选择支段，确认后可拖动端点/轴线点、增删控制点、反转、撤销。修改不能跨出掩膜或越过缺口。
6. “计算长度 / 方向 / 宽度”显示投影结果；“查看横截面强度轮廓”逐条查看原始强度与有效高斯拟合。
7. 两侧独立标记亮结或弯折。相同特征使用相同编号；人工身份确认不是三维重建验证。
8. 保存为新标注目录。不要修改自动导出的文件；恢复时会检查校验和。

调阈值可能使原区域消失、分裂、与其他区域合并，或使点击点退出区域；这些情况必须重新选择。
只要重新分割，原轴线就失效，需要重新提取和确认。撤销可以回到先前状态。
推测延伸以虚线保存，不计入实测长度。

## 差分与坐标

差分必须与原图位于同一原生像素网格，带 `JETREG=T`、匹配原图 SHA256 的 `JORIGHSH`，以及配准审计。
程序检查尺寸和五个位置的 WCS，偏差不得超过 0.01 像素。原图本身始终保留，用于横截面高斯拟合。
强度按曝光归一化；已有每秒单位或 `JETNORM=T` 的数据不重复除曝光。
显示色表、拉伸、缩放均不改变测量数组。像素原点为 0，x 为列、y 为行，使用像素中心。

长度为 HPC 折线相邻位置角距离之和。末端方向为最后 20/30/40″ 的弦方向：+Tx 为 0°，+Ty 为 +90°；
不足所需长度时使用实际可见长度。不是三维倾角，也不代表物质速度。
掩膜宽度与原始强度 Gaussian + 常数背景 FWHM 分开保存。多峰、缺测、边界截断、低信号或差拟合返回失败状态。
FWHM 不等于质心误差。默认不平滑测量轴线；科学库的可选平滑必须通过全路径掩膜检查。

## 保存格式

- `annotations.json`：schema/version、图像及差分哈希、观测时间、参数、ROI、方向、原始骨架、自动与修正轴线、对应点和操作历史。
- `view_N_axis.csv`：轴线、骨架和延伸；原生像素、父图像素、HPC 坐标。
- `view_N_tiepoints.csv`：编号、像素/HPC、身份状态及 `verified_3d=False`。
- `view_N_mask.fits`：原图 WCS；0 背景、1 选中区域、255 缺测。
- `COMPLETE.json`：最后写入的校验和清单。未完整同步的标注不会被读取。

原图路径相对于标注目录保存；移动时应一起保留样本与标注目录的相对关系。
操作历史包含每次操作之前的状态；内存保留最近 50 次撤销。加载保存记录后保留历史，但不恢复之前进程的撤销栈。

## 第一轮验证边界

合成场景覆盖直线、弯曲、分叉、交叉、低信噪比、缺测和多峰。骨架端点偏差会影响末端方向；
最长候选不一定是喷流轴。没有端点的闭环骨架明确返回无可确认路径。图像显示为原生采样，界面计算为同步操作，
全尺寸图像或过多骨架分支可能暂时阻塞交互，优先使用已准备的原生像素裁剪样本。

两组中央双视角样本用于调试，其余四组保留验证。中央样本保存后点击“盲重复”独立重做；
不要把旧标注叠加在重复操作上。人工标注前不评价人工辅助的准确度，不启动唯一三维高度计算。
